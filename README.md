# Підбір країни (Country Matcher)

Streamlit-застосунок, який знаходить країни, найближчі до вашого ідеального профілю,
за відкритими даними Світового банку (10 показників у 6 категоріях).

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Застосунок працює офлайн з `data/dataset.csv`. Кнопка «Оновити дані зі Світового банку»
на бічній панелі завантажує свіжі дані (потрібен інтернет). Якщо `data/dataset.csv` немає,
використовуються демо-дані з `data/mock_dataset.csv`.

## Публічне посилання (ngrok)

Один раз: встановіть ngrok (`winget install Ngrok.Ngrok` або https://ngrok.com/download)
і додайте свій токен з https://dashboard.ngrok.com/get-started/your-authtoken:

```bash
ngrok config add-authtoken <TOKEN>
```

Далі одна команда запускає застосунок і тунель та друкує публічну адресу:

```bash
python .ngrok/start.py
```

Посилання відкрите для всіх, хто його має. Кнопка оновлення даних видима лише на вашому
комп'ютері (localhost), тож відвідувачі не можуть запускати завантаження. Ctrl+C зупиняє все.

## Як це працює

1. Кожна країна — вектор із 10 показників, нормалізованих до 0..1 (більше = краще):
   вінзоризація 5–95 перцентиль, логарифм для ВВП, min-max, інверсія «менше = краще».
2. Користувач задає ваги категорій (0–10) і, за бажанням, ідеальний рівень.
3. Рейтинг — найменша зважена евклідова відстань до ідеалу; бал = (1 − відстань) × 100.

Режими: найкраща країна, мій ідеал, схожі на країну, 12 готових профілів (Студент,
Віддалений працівник, Сім'я з дітьми, Пенсіонер, IT-спеціаліст…).

## Можливості

- 15 мов інтерфейсу: українська, English, Deutsch, Français, 中文, Español, Italiano, Português,
  Polski, Nederlands, Čeština, Türkçe, 日本語, 한국어, हिन्दी.
- Рейтинг: стовпчики топ-10, таблиця, карта світу, завантаження в CSV.
- «Чому не X?»: де країна програє лідеру — спершу за категоріями, детальніше за показниками.
- Огляд: точкова діаграма країн за двома категоріями на вибір (за замовчуванням безпека й економіка),
  колір — бал за вашими налаштуваннями.
- Порівняння до 3 країн: радар і таблиця реальних значень з роком даних,
  наприклад «18 905 (2025)», щоб було видно, наскільки свіжі дані.
- Посилання для поширення: адресний рядок зберігає режим, ваги, ідеал і фільтри,
  тож посилання відкриє застосунок з тими самими налаштуваннями.
- Профіль країни: місце в рейтингу, бал, сильні й слабкі сторони з реальними значеннями
  та рівень за кожною категорією.
- На бічній панелі видно, наскільки свіжі дані (наприклад, «значення за 2010–2025 роки»).
- Оновлення даних з командного рядка: `python data_loader.py`.
- Швидкий тест уподобань: 7 життєвих ситуацій (кожну можна пропустити) → ваги критеріїв
  і попередній перегляд найкращих країн ще до застосування.

## Структура

| Файл | Відповідає за |
|---|---|
| `config.py` | показники, категорії, режими (лише id) |
| `data_loader.py` | завантаження зі Світового банку, кеш `data/dataset.csv` |
| `processing.py` | нормалізація до 0..1 |
| `scoring.py` | `match()` — зважена відстань до ідеалу |
| `settings.py` | налаштування за замовчуванням, профілі, посилання |
| `explain.py` | таблиці та пояснення |
| `charts.py` | графіки plotly |
| `i18n.py`, `locales/*.json` | усі тексти: один JSON-файл на мову |
| `app.py` | лише інтерфейс Streamlit |

## Граф проєкту

`graphify-out/graph.html` — інтерактивна карта коду й документації (функції, модулі, зв'язки,
групи). Відкрийте файл у браузері, сервер не потрібен. Короткий звіт — `graphify-out/GRAPH_REPORT.md`.
У git зберігаються лише ці файли та `graph.json`; кеші graphify лишаються локально.
Оновити граф після змін у коді: `graphify update .` (потрібен `uv tool install graphifyy`).
